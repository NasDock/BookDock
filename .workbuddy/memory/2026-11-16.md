## 修复鸿蒙端「退出登录/登录成功不自动跳转」

- 现象：hm 端登录成功或退出登录后页面停在原地，不切到主 Tab/登录页。
- 根因：`router/AppRoot.ets` build() 第122行读 `this.authStore.isAuthenticated`(普通单例字段,无响应式装饰)，不触发 ArkUI 依赖收集。文件虽定义了 `@State isAuthed` 且 subscribe 回调里有更新，但 build 没用它 → 登录/退出 notify 后 isAuthed 变了却不重渲染。(mobile 端正常是因 RootNavigator 读 zustand hook 响应式状态)
- 架构要点：hm AppRoot 根容器用 `Stack + if/else` 直渲 LoginScreen/MainTabNavigator，**没有 Navigation 包裹**；全局 NavPathStack 只在 MainTabNavigator 内部 `Navigation(getNavStack())` 绑定。故登录阶段任何 replaceRoute 都打在空栈上无效，且切到主 Tab 后残留条目会命中 MainTabNavigator.PageBuilder 无 `Main` 分支的「未注册路由」兜底。
- 修复：①`AppRoot.ets` build 判断改 `if (this.isAuthed)`；订阅回调记录 wasAuthed，退出时(wasAuthed && !isAuthed)调 `popToRoot()` 清栈防残留子页面；清理未用 import(getNavStack/RouteName)，改用 popToRoot。②`LoginScreen.ets` 删 3 处 `replaceRoute(RouteName.MAIN)`(扫码/登录/注册成功)及该 import，改靠 authStore 订阅切页。③`SettingsScreen.ets` handleLogout 修正误导注释。
- 验证：hvigor CLI 真编译 `BUILD SUCCESSFUL`，无 ERROR。
