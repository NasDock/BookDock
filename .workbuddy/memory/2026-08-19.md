### 坑：Flex/Wrap 内 `aspectRatio` 不可靠
- RecCard 封面最初用 `.width('100%').aspectRatio(2/3)`，真机渲染塌缩成字母大小。

## ArkUI Scroll 内容默认居中

## RecCard 封面二次塌缩（display 首帧宽度）
- 改完 Scroll 后「为你推荐」封面又塌缩，根因不是 aspectRatio：是 `getRecItemWidth()` 依赖 `onAreaChange`，**onAreaChange 首次回调晚于首帧渲染**，首帧用默认 360vp 算列宽，Flex{wrap} 子项超宽换行后 `width('100%')` 封面失去宽度参照塌缩。
- 解：`@State screenWidthVp = px2vp(display.getDefaultDisplaySync().width)`，首帧就用真实屏幕宽度，不再依赖 onAreaChange 兜底（onAreaChange 保留应对折叠屏/旋转）。

## Profile 头像"掉下来"（Scroll 垂直居中）
- ProfileScreen Tab 内容短时，头像板块整体掉到屏幕下半部分。

- 解：Profile 主 `Scroll` 加 `.align(Alignment.Top)`，强制内容顶对齐。

## ReaderScreen 底部操作栏 + SafeArea 沉浸
- **问题**：底部操作栏在屏幕中间（Stack 默认 Center 对齐），状态栏/手势条区域背景色未沉浸。
- **修复**：
  1. 外层 `Stack()` → `Stack({ alignContent: Alignment.Top })`，顶栏贴顶。
  2. 底栏加 `.position({ y: '100%' }).translate({ y: '-100%' })` 定位到底部。
  3. 通过 `window.getLastWindow().getWindowAvoidArea()` 获取安全区域高度，顶栏 padding-top 加 `safeAreaTop`，底栏 padding-bottom 加 `safeAreaBottom`。
  4. SettingsPanel/ChaptersPanel/ActionSheet 的底部面板也加 `padding({ bottom: safeAreaBottom })`。
- **注意**：`window.getLastWindow` 返回 Promise，必须 `await` 调用。
- 编译 BUILD SUCCESSFUL，布局验证：顶栏 y=108（状态栏下方），底栏 y=2134~2322（屏幕底部），WebView 内容区域 y=108~2322。

## ReaderScreen 顶栏高度 + 加载背景色修复
- **问题1**：阅读页顶栏标题行偏低，与书籍详情页不一致。
  - 根因：阅读页顶栏 `padding-top = safeAreaTop + spacing.sm`，而书籍详情页 header `padding-top = spacing.sm`。
  - 修复：hm 阅读页顶栏 padding-top 改为 `spacing.sm`；mobile 阅读页 `topBar.paddingTop` 从 `spacing.xl`(32) 改为 `spacing.sm`(8)。
- **问题2**：阅读页内容加载时背景色始终是白色，应与当前阅读主题色一致。
  - 根因：`applyReaderTheme()` 在异步 `init()` 中调用，首帧渲染时 `themeBg` 还是默认值 `'#ffffff'`。
  - 修复：`aboutToAppear` 中同步调用 `this.applyReaderTheme()`，确保首帧就有正确主题色。
- 编译 BUILD SUCCESSFUL，布局验证：顶栏 `[0,108][1080,279]` height=171px bg=#FF1A1A1A（深色），底栏 `[0,2134][1080,2322]` bg=#FF1A1A1A，WebView `[0,108][1080,2322]`。

## ReaderScreen 切换章节闪白修复
- **问题**：切换章节时中间区域闪白一下，再显示正常内容。
- **根因**：`Web` 组件没有设置 `backgroundColor`，切换章节时 WebView 重新加载新 HTML，组件默认白色背景在 HTML 渲染完成前露出。
- **修复**：`Web` 组件加 `.backgroundColor(this.themeBg)`，让组件背景色始终与阅读主题一致。
- 编译 BUILD SUCCESSFUL。

## ReaderScreen 沉浸式系统栏颜色
- **问题**：深色/护眼主题时，系统状态栏和底部手势条区域背景色始终是白色（跟随系统主题）。
- **根因**：`setWindowSystemBarProperties` 的 `navigationBarColor` 在非全屏窗口下不生效，手势条区域背景由系统绘制。
- **修复**：阅读页生命周期内开启全屏沉浸：
  1. `aboutToAppear` → `setupImmersive()`：`setWindowLayoutFullScreen(true)` + 获取安全区 + `setWindowSystemBarProperties`（状态栏/导航栏颜色 = `themeBarBg`，图标颜色根据主题明暗切换）。
  2. `aboutToDisappear` → `exitImmersive()`：`setWindowLayoutFullScreen(false)` + 恢复系统栏默认白色。
  3. 顶栏 `padding-top` 恢复 `safeAreaTop + spacing.sm`（全屏后内容从 y=0 开始，需要避让状态栏）。
  4. 底栏 `padding-bottom` 已有 `safeAreaBottom + spacing.sm`，全屏后背景自然延伸到手势条区域。
- **关键**：全屏只影响阅读页，离开时恢复，其他页面不受影响。
- 编译 BUILD SUCCESSFUL，布局验证：底栏 `[0,2134][1080,2406]` y2=2406（屏幕最底部），bg=#FF1A1A1A。
